# DistractedDrivingFatalities

## Dataset
The dataset used in this project is sourced from the National Highway Traffic Safety Administration (NHTSA) Fatality Analysis Reporting System (FARS). It contains detailed information about fatal motor vehicle crashes in the United States, including data on driver distractions.

## Project Structure
- `data/`: Contains the raw and processed datasets.
  - `FARS20*NationalCSV`: Yearly data files from 2010 to 2019.
  - `full_merged_data.csv`: Merged dataset used for analysis.
  - `Fatality Analysis Reporting System Analytical User’s Manual, 1975-2023.pdf`: Dataset documentation.
- `preprocess_data.ipynb`: Jupyter notebook for data preprocessing and merging.
